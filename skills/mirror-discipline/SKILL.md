# SKILL — Mirror Discipline

**Purpose.** The method holds up a mirror. It does not deliver verdicts. This
skill exists because the pull toward verdicts is constant — verdicts feel more
valuable, they demo better, and users often ask for them directly. Resisting
that pull is the product.

## Success criteria

Every output the user reads: (a) is framed as provisional, (b) invites
correction, and (c) leaves the user holding the conclusion. A user should be
able to disagree with the reflection without being wrong.

## The framing — verbatim, on every output

> This is not a final analysis. It is what the method assessed from the
> information provided so far. If the information changes, the analysis and
> outcome can change.

Canonical text: `MIRROR_FRAMING` in `lib/method.ts`. It is appended by our code,
not generated by the model — so it cannot be paraphrased away under any prompt.

Then, always: **"Does this resonate?"** — Yes / Partly / No, and tell us what to
correct.

## Hard gotchas

1. **No scores, no grades, no percentages.** A compatibility number is a verdict
   with a decimal point. The product name was chosen partly to remove the
   pass/fail connotation; do not reintroduce it in the UI.
2. **No rankings of people.** Rank a user's own values, never people.
3. **The user's "No" is data, not error.** When a user says the reflection is
   wrong, the reflection is wrong. Route them to edit the answers it came from
   and regenerate. Never argue in copy.
4. **"Partly" is the most common honest answer.** Design for it. If the UI
   makes "Partly" feel like a failure state, the UI is wrong.
5. **Assumes total honesty.** The mirror is only as true as the input. Say this
   out loud to users rather than hiding the dependency.
6. **A screen that produces a verdict but never a conversation is avoidance in
   analytical clothing.** This applies to the match feature above all: the
   output is a question to raise together, not a sentence to carry out in
   silence.

## Inter-skill communication

- **Empathy Voice** owns the tone inside the frame; this skill owns the frame.
- **Legal & Duty of Care** requires the disclosure on every report; the framing
  here sits alongside it and does not replace it.

## Where this is enforced in code

- `lib/method.ts` — `MIRROR_FRAMING`, `MIRROR_DISCLAIMER`
- `app/profile/page.tsx` — the framing block and the resonance control
- `app/api/synthesize/route.ts` — hard rule 4 in the system prompt
